# Computer Science

## 各目录职责

| 目录 | 放什么 |
| --- | --- |
| `00-foundations/` | 计算机组成、操作系统原理、编译原理等底层概念 |
| `01-programming/` | 具体编程语言，每种语言一个子目录（`python/`、`c/`…） |
| `02-math/` | 高数、线代、概率、离散数学 |
| `03-algorithms/` | 数据结构、算法题、复杂度分析、题解 |
| `04-data-and-databases/` | SQL、数据库原理、数据分析 |
| `05-systems/` | Linux、网络、分布式、运维/部署 |
| `06-ai-ml/` | 机器学习、深度学习、LLM |
| `07-projects/` | 实际动手写的项目代码，一个项目一个子目录 |
| `99-resources/` | 跨主题的书单、课程、工具、速查表 |

## 语言子目录统一结构

```
01-programming/<语言>/
├── notes/        # 语法、特性、坑
├── snippets/     # 可复用小例子
└── exercises/    # 练习题与答案
```
