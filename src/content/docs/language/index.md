# 语言

语言学习。每门语言一个目录，结构统一：

```
<语言>/
├── notes/         # 课文、语法讲解、课堂笔记
├── vocabulary/    # 单词、搭配、例句（可按主题或日期分文件）
├── grammar/       # 语法体系、易错点
├── practice/      # 练习、作文、听力稿、口语录音文字稿
└── resources/     # 教材、音频、字幕、链接
```
